The Soil2Soul + KrishiMitra Story

Our Story

KrishiMitra started as a multilingual WhatsApp assistant for farmers — answering weather questions, showing mandi price trends, and even helping them generate crop insurance documents. Very quickly, the same farmers asked a deeper question: “If I already trust this bot, can it also help me sell my crop better?”

Soil2Soul is our answer. It is a thin but powerful web layer sitting on top of the KrishiMitra backend. Farmers stay on WhatsApp. Retailers and consumers discover them through Soil2Soul. Together, the two pieces behave like one integrated ecosystem.

Team & Performance

Focused on the Full Flow
We designed the data contracts between WhatsApp → backend → web UI first, then wrote code around those shapes. That kept the system debuggable and helped us iterate fast under time pressure.
Shipping Despite Infra Issues
Between flaky Wi‑Fi, slow bundlers, and noisy terminals, we still kept the stack minimal: Express, MongoDB, plain HTML/CSS/JS. No heavy dependencies, no hidden magic.
Farmer-Centric Decisions
Every endpoint and page is built around the question: “Does this shorten the distance between farmer and buyer, or just add another box in the diagram?”

KrishiMitra + Soil2Soul Ecosystem

On WhatsApp, KrishiMitra supports farmers with multiple features — mandi price queries, weather lookups, disease guidance, government schemes, and a detailed crop insurance assistant. The new sixth capability is “Update My Produce”.

When a farmer chooses this option, KrishiMitra calls the Soil2Soul backend’s /webhook/farmer endpoint with JSON describing the produce. The backend upserts that into MongoDB and instantly checks which retailer requirements might match it. On the web side, Soil2Soul’s marketplace and requirement pages consume the same APIs to show live supply and demand.

Where We Want to Go Next

This hackathon build is deliberately simple: no login, no payments, no heavy GIS. But the architecture is ready for the next iteration — trust scores, live logistics integration, more precise geolocation, and analytics that show farmers how much closer they are to the consumer rupee when they sell through Soil2Soul.

Thank you for exploring Soil2Soul.
